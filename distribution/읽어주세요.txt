삼국지14 CE (한국어판) AI 모드 설치 안내

[버전]
v13.3: 경로 탐색 가속의 메모리 누수 긴급 수정판(미서명).
이 ZIP의 버전은 AI_TacticsMod/build/input_package/manifest.json의 release_version이 기준입니다.
기존 dist의 구버전 ZIP도 보존됩니다. 작업공간의 최신 설치 상태와 ZIP 버전은 다를 수 있습니다.

[설치·설정·복구]
1. 게임과 런처를 완전히 종료합니다.
2. ZIP 전체를 SAN14CE_KO.exe가 있는 폴더에 풉니다.
3. AI모드_설치관리자.exe에서 기능을 선택하고 '설치 / 적용'을 누릅니다.
   다른 위치에 풀었다면 '게임 폴더 변경'으로 게임 EXE를 선택합니다.
4. 기능만 바꿀 때는 '설정만 저장' 후 게임을 재시작합니다.
5. 제거는 '모드 해제 (원본 복구)'를 사용합니다.
GUI를 쓸 수 없으면 게임 루트의 AI모드_적용.cmd / AI모드_해제_원본복구.cmd를 사용합니다.

[현재 기능]
전투 / 편의성 / 성능 / 게임성 / 기타(개발용) 탭, 묶음 포함 74개 항목입니다.
새 설치 기본값은 대부분 켜짐이며 통합 인사·1군단 자동 내정·건물파괴 지역 전체 피해는 꺼짐입니다. 기존 설정값은 보존합니다.
자동 내정은 2군단 이후·컴퓨터 세력이 기본 대상입니다.
1군단은 domestic_direct를 켰을 때만 개발 항목을 바꾸며, 임명 비용은 항상 원작 값입니다.
속도 버튼 >>>> ×4 / >>>>> ×8은 기존 >>> 대비이며 60fps 기준입니다(30fps 최대 ×4).
자동점령 연출은 원작의 약 1/4입니다. 과거 ×2/×3.5·절반 설명은 이전 구현입니다.
v12.11은 기존/수정된 SAN14_전법설명.txt를 보존하며 설치·업데이트·복구를 막지 않게 합니다.

[보존과 확인 범위]
dinput8.dll(로더) / SAN14_CombatAI.dll(전투) / SAN14_Convenience.dll(편의)을 관리합니다.
원본 EXE·사용자 세이브를 직접 수정하지 않으며 설치 전 파일은 고유 backup에 보존합니다.
개성9·속도 버튼 화면 자료는 ScreenLayout의 해당 항목만 병합합니다.
v12.9 실행 중 종료 보고는 원인 미확인입니다. 과거 버튼·빠른 저장/로드 사용자 확인은
현재 ×8의 두 번째 프레임 호출이나 모든 기능 조합의 안정성 확인을 대신하지 않습니다.
