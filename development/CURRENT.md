# 공개 소스 스냅샷

기준일: 2026-10-26. 작업 폴더의 개발 소스이며 정식 v13.3 배포 DLL의 정확한 재현 소스로 보장하지 않는다. 이 파일은 개인 설치 상태를 나타내지 않는다.

군사의 열흘 보고, 숙련 설정 UI 등 개발 후보·미연결/이전 설계도 존재한다. 파일의 존재만으로 기능 활성화·설치·실게임 검증을 추정하지 않는다. 현재 실행 경로는 build defines, MODULES, native_split_install.inl을 함께 확인한다.
