# 건물파괴 지역 전체 피해

설치관리자의 **게임성 → 건물파괴 지역 전체 피해**. 편의 묶음(SAN14_Convenience.dll) 소유이며 전투 DLL 없이도 동작한다. 기본값은 꺼짐이고, 설정을 바꾸면 게임을 재시작한다.

```ini
[stratagem]
building_destruction_all=1
```

## 동작

- 기존처럼 계략 → 건물파괴 → 지역 → 실행 무장을 선택한다.
- 성공하면 원작이 계산한 피해량을 그 지역의 모든 적 소유 군사시설·장애물·함정에 각각 적용한다. 피해량500이면 각 건물에500이며 나눠 주지 않는다.
- 원래 선택된 건물은 원작이 한 번만 처리한다. 원래 건물의 남은 내구가100이어도 다른 건물에는500을 적용한다.
- 성·관문·아군·동맹·중립 소유 건물 및 다른 지역은 제외한다. 내구0은 원작 철거 경로를 사용한다.
- 원작의 성공 판정·비용·실행 무장·추가 함정 제거·결과 반환을 유지한다. 실패 때에는 원작의 소량 내구 피해만 남긴다. 재판정하거나 난수를 추가로 굴리지 않는다.
- 플레이어·컴퓨터가 같은 원작 건물파괴 처리 경로를 사용하면 모두 적용한다.

## 구현과 검증

`native_building_destruction.inl`에서 원작 종류20 CALL과 성공 피해 계산8바이트만 연결한다. 성공 때 대상을 읽기만 하여 기록한 후, 원작 처리가 끝난 동일 UI/AI 호출 스레드에서 나머지 대상에 피해를 적용한다. 원작이 제거한 함정이나 소유·지역·타입·슬롯이 바뀐 대상은 다시 확인하여 제외한다. 코드 지문이 다르면 훅을 게시하지 않는다.

검사 경로: `tools/check_feature.ps1 -Feature building-destruction -Build`. 결과·빌드·소스 해시는 `build/development/building_destruction/verification.json`에 기록한다. 실패/OFF/중복/낮은 주 대상 내구/전체 적 분류/동맹·중립·거점 제외/콜백 변경/재진입/실제 기계어 브리지/지문 변조·게시 원복을 검사한다. 자동 검사는 실게임에서 건물 내구를 대조한 결과와 구별한다. 현재 설치 여부는 CURRENT를 따른다.

세력 식별은 군주 무장 번호와 분리한다. Force+10은 군주 Person 번호이므로 세력 번호로 사용하지 않고, 월드 세력 표의 객체 일치로 식별한다. 군주 번호850인 세력이 번호1인 경우를 포함하여 검사하며, 진단 로그의 `building_destruction_capture`와 `building_destruction_area`로 대상 수와 실제 추가 적용 수를 구별한다.
