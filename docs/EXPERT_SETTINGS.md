# 숙련 모드 공방·인접효과

`SAN14_Convenience.dll`만 UI·값·툴팁·계수 훅을 게시한다. 스위치는 `[battle_rules] battle_rules`이며 편의 묶음이 필요하다. 두 인접효과 행은 소·중·대를 하나씩 선택한 뒤 표준으로 적용한다. 수정 후 실제 화면 배치·클릭·저장 재로드는 별도 확인 대상이다.

시나리오 선택 → 군주 선택 → **숙련 모드 진입 후 설정2**에서 설정합니다.
포위점령 다음에 자세력/타세력 기본 공방 두 줄이 있습니다.

| 설정 | 범위 | 표준값 |
|---|---:|---:|
| 자세력 기본 공/방 | 50~200 | 100 |
| 타세력 기본 공/방 | 50~200 | 100 |
| 자신세력 인접지역 효과 | 0~200 | 현재 난이도·소/중/대 선택값 |
| 타세력 인접지역 효과 | 0~200 | 현재 난이도·소/중/대 선택값 |

두 행 각각 표준 오른쪽에 소·중·대 버튼이 있으며, 처음에는 미선택으로 표준이 비활성이다.
선택만으로 수치는 바뀌지 않고 표준 클릭 시 설정1의 현재 난이도로 적용한다. 두 세력은 독립적으로 선택한다.

| 난이도 | 자세력 소/중/대 | 타세력 소/중/대 |
|---|---|---|
| 초급·중급·상급 | 4 / 25 / 46% | 4 / 25 / 46% |
| 특급 | 4 / 25 / 46% | 16 / 39.2 / 62.5% |
| 궁극 | 4 / 25 / 46% | 24 / 49 / 74% |

궁극에서 중을 선택하고 표준을 누르면 자세력25%, 타세력49%다. 기본 공방값은 유지한다.
특급의39.2%·62.5%는 표시·계산·저장에 소수 한 자리를 보존한다. 수동 슬라이더/숫자 입력은 정수다.
원작 화면 자료의 숫자 행에 버튼 노드48~50을 추가하며 기존 개성·속도·군주교체 화면 항목을 보존한다.

기존 부대마다 계산되는 무장·진형·병력·사기 등의 원작 공방은 그대로 사용합니다.
그 계산 중 인접지역 배율만 `기본 공방 설정 / 100 + 인접효과 설정 / 100 × 완전 점령 지역 수`로 바꿉니다.
1000은 설명용 예시이며 모드가 부대 공방을1000으로 설정하지 않습니다.
부분 점령 비율과 원작 세력 특성 가산도 보존합니다.

예를 들어 인접효과 적용 전 공방177, 기본 공방50, 인접효과200이면
완전 점령4개에서 `177 × 8.5 = 1504.5`, 1개에서 `177 × 2.5 = 442.5`입니다.
다른 보정이나 표시 반올림이 없다는 예시이며 모든 부대의 공방이 같아지는 방식이 아닙니다.

부대 정보·예측에는 설정된 배율을 표시합니다. 실제 플레이어가 포함된 적대 전투에도 사용합니다.
컴퓨터끼리의 실제 전투는 별도 경로에서 기존 기본 배율1·인접4%를 유지합니다.
성·시설만의 계산에 새 부대 기본값을 넣지 않습니다.
설정은 원작 옵션 메모리와 저장/불러오기 경로를 사용하며 계산마다 파일을 읽지 않습니다.
v11.18 설정 저장 형식과 호환됩니다. 새 형식의 저장은 이 모드와 함께 사용합니다.

목록 위치 인자의 실제 XMM1 전달을 검사해 이전 코드의 실패를 재현했고 수정 후 통과했습니다.
기존 원작 공방177/403, 기본50·인접200, 지역4/1, 두 원작 지역효과 소비 경로,
컴퓨터끼리4%, 성 제외, 실제 DLL의7바이트 진입 게이트·인자 전달·원복을 검사했습니다.
검사2185개와 세 DLL 무로그 빌드를 통과했습니다.
실제 게임의 수정 후 화면·저장 재로드·공방 표시·장기 안정성은 별도 확인 전입니다.

현재 소스: `src/expert_combat_settings.h`, `src/native_expert_settings.inl`, `src/native_expert_links.inl`, `src/native_adjacency.inl`. 검사 경로는 `expert-combat`, 소유권 변경 시 `dll-split`이다. 위 과거 2185개 수치는 당시 검사이며 이번 문서 정리에서 다시 실행하지 않았다.
