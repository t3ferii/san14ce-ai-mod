# 설치·배포 대조 (v12.22-rc1)

2026-10-22~23 조사 기준이다. 현재 로컬 설치는 `v12.21-recheck-fix-local1` 진단판이고, 기존 GitHub 정식 배포는 `v12.21`이다. 로컬 설치·Apply·manifest의 세 DLL 해시는 일치했고, 설치 기록의 소스와 현재 소스의 차이는 없었다. 이번 배포는 같은 소스를 `NO_RUNTIME_LOG`로 새로 빌드한 시험 배포다. 사용자 게임 DLL·설정·원본 EXE·기존 ZIP은 교체하지 않았다.

|---|---|---|
| dinput8.dll | `292b12e63f5d30157c12eb454e300a9d4c41f7dbd84736fa50019c011bb54017` | `b09ab4f344c4c6a1e55ea47fa74f99e9cba230556003c3caa3b25b603a79e7af` |

해시 차이는 빌드 종류와 빌드 시점 차이를 포함한다. 소스 차이 없이도 동일한 바이너리 해시가 보장되지는 않는다. 지원 원본 EXE SHA256은 `87ed4e46590e0939c9efcaef14fa0f892917604dfda86e0a4be319fccffa2d6a`이며 해당 EXE는 배포에 포함하지 않는다.

## 확인한 범위

- 필수 `dll-split -Build` 전 경로 및 `-RuntimeDiagnostics` 빌드 통과. 전투 판단·편의·로더의 소유 경계 유지, 공개 DLL은 런타임 기록 제외.
- 일반 어댑터1595개, 출진2032개, 분리 경계37개·실패 원복20개, 로더63개·내보내기8개 통과. 관련 인사·내정·저장·통합 인사 회귀 검사도 필수 경로에서 실행했다.
- 건물파괴176개·지문9범위, 피해 표시70개·지문12범위 통과.
- 설치기57항목: 정적262개·설정 왕복76개 통과. 실제 게임 화면 클릭 검사는 아니다.
- 일반 ZIP133개·EXE 없는 ZIP131개 격리 설치/갱신/복구 통과. 기존 입력 제공 DLL 유무·구버전 이관·미지원 EXE 거부·복구를 검사했다.
- ZIP에는 원본 EXE·세이브·백업·로그·PDB·별도 INI를 넣지 않았다. 수신자의 기능설정.ini는 설치기가 생성·이관한다. 기존 설정은 보존한다.

## 남은 확인

미서명이다. 예상 피해 표시는 일부 사용자 화면 확인 기록이 있으나 실제 병력/내구 감소량 대조는 남아 있다. 건물파괴 전체 피해 수정 후 실게임 대조, 새 AI의 출진·회군 결과, 모든 기능 조합과 장기 안정성도 미확인이다. 시험 배포라는 구분은 이 범위를 반영한다.
