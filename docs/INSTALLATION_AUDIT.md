# 설치·배포 대조 (v12.22-rc2)

2026-10-23 조사 기준이다. 로컬 설치는 `v12.21-corridor-local1` 진단판이며 세 DLL의 설치·Apply·manifest 해시와 설치 당시 소스 기록이 일치했다. rc1과 비교한 런타임 소스 변경은 `src/native_campaign.inl`의 회랑 후보 추가다. 같은 소스를 공개용 NO_RUNTIME_LOG 빌드로 새로 만들었으며, 사용자 게임 DLL·설정·원본 EXE·기존 ZIP은 교체하지 않았다.

해시는 빌드 종류·시점에 따라서도 달라진다. 설치기 EXE와 설정 카탈로그는 rc1 공개판과 동일하다. 지원 원본 EXE SHA256은 `87ed4e46590e0939c9efcaef14fa0f892917604dfda86e0a4be319fccffa2d6a`이며 해당 EXE는 배포하지 않는다.

## 자동 검사

필수 dll-split -Build 전 경로를 다시 실행했다. 일반 어댑터1598개·출진2035개, 분리 경계37개·실패 원복20개, 로더63개·내보내기8개와 인사·저장·통합 인사 회귀 검사가 통과했다. 새 회랑3개 검사는 항구·성/관문·긴 우회 구분, 기존 목록 보존, 목표별1회 제공과 목표 변경을 확인한다. 설치기·예상 피해량·건물파괴는 rc1과 소스/카탈로그 변경이 없으며 관련 기능별 검증 기록은 rc1 설명을 참조한다. 모의 검사는 실게임 확인이 아니다.

진단 빌드도 통과했다. 최종 ZIP 설치·갱신·복구는 일반판133개·EXE 없는 판131개를 통과했다. 두 ZIP의 SHA256은 릴리스 설명에 기록했다. 패키지에는 원본 EXE·세이브·백업·로그·PDB·별도 INI를 넣지 않는다. 수신자의 기능설정.ini는 설치기가 생성·이관한다.

## 실게임 확인 범위

미서명이다. 새 회랑의 점령·진군 결과, 모든 기능 조합과 장기 안정성은 미확인이다. rc1의 예상 피해량 실제 감소량 대조·건물파괴 전체 적용 확인도 남아 있다. 시험 배포라는 구분은 이 범위를 반영한다.
