# 모드 출진 변경 지점

[원작 출진 판단 흐름](AI_FLOW_ORIGINAL.md)의 회로는 회색으로 두고, 모드가 선 위에 끼워 넣은 부품을 색으로 표시했습니다. 대부분 컴퓨터 세력에만 적용되고, 플레이어 직할 부대는 건드리지 않습니다. 켜짐 표시는 2026-11-12 개발 설정 기준이며, 설치기에서 고른 값에 따라 달라집니다.

**그림 읽는 법**: 회색은 원작입니다. 색 부품의 왼쪽 띠가 종류입니다. **변경**은 원작 값을 바꿈, **추가**는 원작에 없던 판단, **차단**은 원작 행동을 막음입니다. 부품 오른쪽 위는 설정 키 이름입니다.
