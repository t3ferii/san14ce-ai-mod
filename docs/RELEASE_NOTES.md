# 삼국지14 CE AI·편의·최적화 모드 v12.21

v12.20의 게임 기능과 DLL을 그대로 유지하고, **모드 해제(원본 복구)**를 보완한 판입니다.

- 모드 해제 후에도 진행 속도 팝업의 4·5번째 버튼(×4·×8)과 개성 9칸 화면이 남는 경우가 있었습니다. 설치 기록에 화면 레이아웃 정보가 없거나 오래된 경우에도, 해제할 때 모드가 바꾼 ScreenLayout 항목 8개를 원본 항목으로 되돌리고 모드 전용 레이아웃 파일(bin24~31 중 모드 것)을 지웁니다.
- 이미 해제된 상태에서 화면이 남아 있으면 **모드 해제를 한 번 더 누르면** 정리됩니다.
- 다른 화면·얼굴 모드가 쓰는 레이아웃 항목과 파일은 건드리지 않습니다. 모드 패치와 위치(오프셋·크기)가 정확히 같은 항목만 되돌립니다.
- 게임 DLL 세 개와 설치 관리자 EXE는 v12.20과 같습니다. 원본 게임 EXE와 사용자 세이브는 배포하지 않습니다. 코드 서명은 없습니다.

[모드가 바꾸는 전체 내용과 설치 방법](https://github.com/t3ferii/san14ce-ai-mod#readme)

설치: 아래 SAN14_AI_v12.21_integrated.zip 전체를 압축 해제 → AI모드_설치관리자.exe → 게임 폴더 선택 → 설치 / 적용. 기능 설정을 바꾼 후 게임을 다시 시작하세요. 해제는 원본 복구를 사용합니다.

통합 인사와 1군단 자동 내정은 새 설치에서 기본 꺼짐입니다. 기존 설정은 보존합니다. 한국어 Complete Edition 지원 빌드용입니다.

게임을 실행한 검증과 자동 검사는 다릅니다. 해제 복구는 실제 ScreenLayout 색인 사본으로 21개 검사(기록 없음·오래된 기록·해제 후 잔여·다른 모드 항목 보존)와 배포 ZIP 설치·복구 검사 133개를 통과했습니다.
