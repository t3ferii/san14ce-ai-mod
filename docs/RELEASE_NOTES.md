  - 적 부대가 거점 8칸 안으로 다가오면 빼앗기기 전에 미리 나옵니다.
  - 성 주변과 그에 이어진 지역 가운데 적 부대가 가장 많이 몰린 지역 하나는 최대 위협으로 보고, 가지도 지나가지도 않습니다. 나머지 거점을 가까운 순서로 차례로 되찾습니다.

**지형을 직접 바꾸는 「부동산 계획」과 군사의 열흘 보고를 더한 판입니다.** 공개 DLL은 진단 로그를 제외한 **미서명** 빌드입니다.

## 새 기능
- **부동산 계획: 지형 변경**(게임성, 기본 ON) — 지역내정에서 거점·성·관문 칸은 담당관 임명, 그 밖 도시권 칸은 클릭한 칸 위에 지형 선택 창이 뜹니다(무료·무제한).
  - 바닥 재질, 높이(산 능선이 이어지게 보간), 부대가 서는 높이, 숲·밀림 나무 생성/제거, 절벽 경사, 물 깊이가 바로 반영됩니다.
  - 바꾼 지형은 세이브 옆 `.terrain`에 함께 저장되고, 원래 지형으로 되돌리면 원본으로 복원됩니다. 이동 비용도 즉시 다시 계산합니다.
  - 아직: 격류의 흰 물살은 생기거나 사라지지 않습니다. 급류(이동 불가)의 칸 테두리는 저장 후 다시 불러오면 표시됩니다.
- **군사의 열흘 보고**(편의성, 기본 ON, 시험) — 진행 중 뜨는 통지·대사를 좌하단 군사 알림함에 모아 보여 줍니다. 외교·처분 등 선택 창은 그대로 뜹니다.
- **외교 군정 100% 초과 투입 / 마지막 추가 대응**(게임성, 기본 ON) — 컴퓨터가 시작한 교섭에서 보유 군정까지 방어 투입하고, 컴퓨터의 마지막 응답 뒤 한 번 더 대응할 수 있습니다.
- **플레이어 성 주변 컴퓨터 투석대 건설 불가**(전투, 기본 OFF) — 플레이어 성·관문 지역과 바로 붙은 지역에서 컴퓨터가 투석대를 짓지 않습니다.

## 바뀐 점·수정
- 목표를 잃고 할 일이 없는 건강한 컴퓨터 부대는 원작처럼 퇴각합니다(같은 자리 40일 대기 방지).
- 임무 일관성 v2와 충돌하던 정기 선제 출진·집단 진군·호위 지원 옵션을 사용 중지했습니다.
- 속도 ×4/×8에서 턴마다 진행 슬롯이 새어 탐색 발견 등이 멈추던 문제를 고쳤습니다.
- AI 등용 후보 정리의 반복 순회와 대량 로그를 줄였습니다.

## 검증 범위
- 지형 변경: 사용자 실게임에서 재질·높이·부대 높이·나무·절벽·수면과 프레임(평균 약 18ms)을 확인했습니다(진단판). 공개 무로그판은 실게임 미실행입니다.
- 군사 보고·외교 군정·투석대 옵션·퇴각 수정: 모의 검사와 필수 분할 빌드 검사 통과, 실게임 확인은 일부 또는 미확인입니다.

**설치:** 게임 종료 → 설치기 포함 ZIP 전체 압축 해제 → `AI모드_설치관리자.exe`에서 **설치 / 적용**. 기존 설정은 보존되며, 새 기능은 설치기에서 끌 수 있습니다. `_noexe.zip`은 설치기 EXE 제외판입니다.

# 삼국지14 CE AI·편의·최적화 모드 v13

v12.22-rc5 이후 **등용 다중 선택**과 **다른 패치와 함께 설치할 때의 호환**을 더한 판입니다. 공개용 무로그 빌드이며 **미서명**입니다.

## rc5 이후 변경점

- **등용 대상무장 다중 선택**(편의성 「등용 보조」): 별도 「자동등용」 버튼을 없애고 원작 등용 화면에 통합했습니다.
  - 대상무장 선택창에서 명령서로 보낼 수 있는 수만큼 여러 명을 고를 수 있습니다. 마지막 무장이 대상 칸에 「○○ 외 N명」으로 표시되고, 실행무장·군사 조언·일수는 원작이 계산합니다.
  - 명령서 미리보기에 추가 대상 수가 반영됩니다(군사가 반대한 대상은 실제로 보내지 않으므로 실제 차감이 더 적을 수 있습니다).
  - 결정·연속입력 때 나머지 대상은 군사가 권하는 실행무장만 골라 보냅니다. 화면 대상도 고른 실행무장 중 군사 추천이 없으면 보내지 않습니다. 보내지 않은 대상 수는 결과 안내에 표시합니다.
  - **1명만 고르면 원작과 같습니다.** 군사 조언이 반대여도 결정하면 보냅니다.
- **통합패치 등과 함께 설치할 때의 호환**:
  - 게임 코드 전체 해시가 달라도 바로 멈추지 않고, 여러 기능의 원작 자리 12곳으로 Steam 보호 해제 완료를 판정한 뒤 진행합니다. 원작 EXE 그대로면 기존과 같은 경로입니다.
  - **켜진 기능의 원작 자리만** 검사하고, 다르면 **그 기능(과 하위 기능)만** 끕니다. 꺼 둔 기능의 자리는 검사하지 않습니다.
  - 전투 AI DLL과 편의 DLL을 따로 설치합니다. 한쪽이 실패해도 다른 쪽은 켜집니다.
  - 전체 지문이 없는 「툴팁 협력」·「전사 연출」은 코드가 다를 때 꺼집니다.
  - 겹치는 기능은 설치 관리자에서 꺼 두는 것을 전제로 합니다. 다른 패치가 고친 원작 함수를 모드가 호출할 때의 결과는 보장하지 않습니다.
- rc5의 Steam 보호 섹션(`.bind`)이 없는 같은 빌드 EXE 설치 허용을 유지합니다.

## 설치

게임 종료 → `SAN14_AI_v13_integrated.zip` 전체 압축 해제 → `AI모드_설치관리자.exe` → 게임 폴더 선택 → 설치 / 적용. `_noexe.zip`은 설치기 EXE 제외판입니다. 기존 설정은 보존합니다.

## 검증 범위

- 등용 다중 선택: 사용자 실게임에서 여러 명 파견·「외 N명」·군사 반대 제외·1명 원작 동작을 확인했습니다(로컬 진단판).
- 호환 설치: 분할 설치 모의 검사 14경로(기능 하나만 다름·꺼진 기능 자리 다름·전투만 실패·편의만 실패·발행 실패 원복 등)를 통과했습니다. **실제 통합패치를 설치한 게임에서의 확인은 없습니다.**
- 필수 분할 빌드 검사 전체, core·등용·인사 모의 검사를 통과했습니다.

# 삼국지14 CE AI·편의·최적화 모드 v12.22-rc4 (시험 배포)

전략중이 끝난 뒤 1일이 시작되기까지의 대기(0일 부대 등장)를 줄이는 성능 기능 세 가지를 추가합니다. rc3에서 충돌이 보고된 숙련 설정 인접효과 선택은 이후 로컬 설치본(v12.21-adjpreset-local11)의 수정판을 기준으로 합니다. 공개용 무로그 빌드이며 **미서명**입니다. rc3는 격리 상태로 재배포하지 않습니다.

## rc2 이후 변경점

- **부대 등장 묶음 처리**(성능, 기본 ON): 원작은 출진 부대의 지도 깃발·정보 패널을 프레임마다 1개씩 만들고, 무거우면 1프레임을 쉽니다. 한 프레임 50ms 예산 안에서 여러 부대를 처리하며, 가장 느린 부대만큼 여유가 있을 때만 다음 부대를 시작합니다. 부대·순서·결과는 원작과 같습니다.
- **부대 깃발 지휘관 얼굴 상주**(성능, 기본 ON): 한 번 불러온 지휘관 얼굴을 해제하지 않아 같은 지휘관이 다시 출진할 때 다시 불러오지 않습니다. 최대 256명, 얼굴 하나에 최대 약 2.5MB(256명이면 약 600MB 이하)를 더 씁니다.
- **출진 지휘관 얼굴 미리 요청**(성능, 기본 ON, 얼굴 상주 하위): 새 얼굴마다 한 프레임씩 기다리던 적재를 부대 등장 직전에 한꺼번에 요청해 겹칩니다. 깃발에 붙이기 직전에는 원작과 같이 적재 완료를 확인해 빈 얼굴을 막습니다.
- 설치기 「성능」 탭에서 「지도 메뉴 클릭 대기 감소」가 성능 묶음 밖에 표시되던 배치를 고쳤습니다. 숙련 설정2 인접효과 소·중·대 선택(rc3)의 수정판을 포함합니다. 설정 카탈로그 69개 항목(5개 탭).
- 개발용 탭의 「하루 처리 단계 기록」·얼굴 지정 시간 측정은 진단판 전용이며 이 공개 DLL에는 기록 코드가 포함되지 않습니다.

# 삼국지14 CE AI·편의·최적화 모드 v12.22-rc3 (시험 배포)

- 두 인접효과 행 각각 `[표준] [소] [중] [대]`. 처음에는 미선택으로 표준 비활성, 하나를 선택한 뒤 표준을 누르면 현재 난이도의 값으로 적용합니다. 선택 자체는 수치를 바꾸지 않습니다.
- 자세력 소/중/대는 모든 난이도에서4/25/46%. 타세력은 초급·중급·상급4/25/46%, 특급16/39.2/62.5%, 궁극24/49/74%입니다. 기본 공방은 보존하며 컴퓨터끼리 전투는4%를 유지합니다.

# 삼국지14 CE AI·편의·최적화 모드 v12.22-rc2 (시험 배포)

rc1 이후 설치된 `v12.21-corridor-local1`의 전투 AI 수정을 공개용 **무로그 빌드**에 반영했습니다. 미서명이며 회랑 동작의 실게임 확인이 남아 시험 배포로 제공합니다. 정식판 v12.21과 rc1은 보존합니다.

## rc1 → rc2 변경점

- **공성 경로 주변 점령 후보 확대**: 임무 일관성 v2에서 출진 성과 목표 성 사이의 적·무주 지역을 원작 군세 작업 목록에 추가합니다. 목표 성의 인접 효과를 제공하는 주변 지역을 우선 후보로 삼습니다.
- **최대3개·최단 연결수+1**: 지형 칸 수가 아닌 지역 인접 그래프 기준입니다. 최단 연결 경로보다 1개 지역까지 긴 범위만 검토하고 조건에 맞는 항구도 포함합니다. 성·관문은 중간 경유하지 않으며 먼 우회 지역·아군/동맹 지역·중복 항목을 제외합니다.
- **원작 작업 보존**: 기존 목록10칸의 빈칸에만 추가하고, 목표별 한 번만 제공해 소비한 목록을 반복 보충하지 않습니다. 실제 점령 배정과 공성 시작은 원작 AI가 결정하며 모든 후보의 점령을 강제하지 않습니다.
- **설정과 구성 유지**: 새 설정이나 훅은 없고 기존 `combat.mission_v2`(새 설치 기본 ON)에서 적용됩니다. 5개 탭·57개 항목, 예상 피해량·건물파괴 전체 피해 등 rc1 기능을 유지합니다. 건물파괴 전체 피해·통합 인사·1군단 자동 내정은 새 설치 기본 OFF입니다.

rc1과 비교한 런타임 소스 변경은 `native_campaign.inl`의 회랑 후보 추가입니다. 편의 기능·설치기 설정 구조는 바꾸지 않았으며, 사용자 게임 설치를 이번 업로드 때문에 교체하지 않았습니다. 공개용 빌드는 로컬 진단 DLL과 해시가 다릅니다.
