# 삼국지14 CE AI·편의·최적화 모드 v12.22-rc2 (시험 배포)

rc1 이후 설치된 `v12.21-corridor-local1`의 전투 AI 수정을 공개용 **무로그 빌드**에 반영했습니다. 미서명이며 회랑 동작의 실게임 확인이 남아 시험 배포로 제공합니다. 정식판 v12.21과 rc1은 보존합니다.

## rc1 → rc2 변경점

- **공성 경로 주변 점령 후보 확대**: 임무 일관성 v2에서 출진 성과 목표 성 사이의 적·무주 지역을 원작 군세 작업 목록에 추가합니다. 목표 성의 인접 효과를 제공하는 주변 지역을 우선 후보로 삼습니다.
- **최대3개·최단 연결수+1**: 지형 칸 수가 아닌 지역 인접 그래프 기준입니다. 최단 연결 경로보다 1개 지역까지 긴 범위만 검토하고 조건에 맞는 항구도 포함합니다. 성·관문은 중간 경유하지 않으며 먼 우회 지역·아군/동맹 지역·중복 항목을 제외합니다.
- **원작 작업 보존**: 기존 목록10칸의 빈칸에만 추가하고, 목표별 한 번만 제공해 소비한 목록을 반복 보충하지 않습니다. 실제 점령 배정과 공성 시작은 원작 AI가 결정하며 모든 후보의 점령을 강제하지 않습니다.
- **설정과 구성 유지**: 새 설정이나 훅은 없고 기존 `combat.mission_v2`(새 설치 기본 ON)에서 적용됩니다. 5개 탭·57개 항목, 예상 피해량·건물파괴 전체 피해 등 rc1 기능을 유지합니다. 건물파괴 전체 피해·통합 인사·1군단 자동 내정은 새 설치 기본 OFF입니다.

rc1과 비교한 런타임 소스 변경은 `native_campaign.inl`의 회랑 후보 추가입니다. 편의 기능·설치기 설정 구조는 바꾸지 않았으며, 사용자 게임 설치를 이번 업로드 때문에 교체하지 않았습니다. 공개용 빌드는 로컬 진단 DLL과 해시가 다릅니다.

## 설치와 확인 범위

게임 종료 → `SAN14_AI_v12.22-rc2_integrated.zip` 전체 압축 해제 → `AI모드_설치관리자.exe` → 게임 폴더 선택 → 설치 / 적용. 기존 설정은 보존하며 변경 후 게임을 재시작합니다. 해제는 원본 복구를 사용합니다. `_noexe.zip`은 설치 관리자 EXE를 제외한 판이며 동봉한 적용·해제 CMD를 사용합니다.

한국어 Complete Edition 지원 빌드용입니다. 원본 EXE·세이브·백업·개발용 로그·PDB·별도 INI를 배포하지 않습니다. 설치기가 기능설정.ini를 생성·이관합니다.

필수 dll-split -Build와 로컬 진단 빌드가 통과했습니다. 일반 어댑터1598개·출진2035개, DLL 경계37개/실패 원복20개·로더63개·배포 노출8개와 관련 인사·저장 회귀 검사를 다시 실행했습니다. 회랑3개 검사는 항구 포함·성/관문/긴 우회 제외, 기존 목록 보존, 목표별1회 제공·목표 변경을 확인했습니다. 최종 ZIP의 격리 설치·업데이트·복구는 설치기 포함판133개, EXE 없는 판131개를 통과했습니다. 설치기 EXE와 설정 카탈로그는 rc1과 동일합니다. 자동 검사와 실제 게임 관찰은 다릅니다. 새 회랑의 점령·진군 결과, 예상 피해와 실제 감소량 대조, 건물파괴 전체 피해, 모든 기능 조합과 장기 안정성은 미확인입니다. v12.9의 종료 보고 원인은 미확정입니다.
