# 삼국지14 CE AI·편의·최적화 모드 v12.20

v12.19의 게임 기능을 유지하면서 설명서와 배포 구성을 정리했습니다.

- DLL별로 나뉘어 있던 설명을 전투·군단·내정·인사·화면·성능별로 다시 정리했습니다. 설치기44개 항목과 공통 동작·시험 기능·기본값을 확인할 수 있습니다.
- 빠져 있던 무공 논공 병력 +3000/+3000/상호친애, 대열 이동속도 통일, 지역 점령 인력, 명품·관직 수여 제한도 설명에 포함했습니다.
- 필요 없는 SAN14_전법설명.txt를 새 배포에서 제외했습니다. 옛 설치 기록에 남아 있어도 업데이트·복구할 수 있도록 보완했습니다. 다른 사용자가 수정한 기존 TXT는 자동 삭제하지 않습니다.
- 플레이어 지원 군단은 수송만, 내정 군단은 군사 출진을 막고 수송·건설은 허용하는 v12.19 규칙을 유지합니다. 적 근접 거점의 수송 출발지 보완도 포함됩니다.
- 게임 DLL 세 개는 v12.19와 동일합니다. 원본 게임 EXE와 사용자 세이브는 배포하지 않습니다. 코드 서명은 없습니다.

[모드가 바꾸는 전체 내용과 설치 방법](https://github.com/t3ferii/san14ce-ai-mod#readme)

설치: 아래 SAN14_AI_v12.20_integrated.zip 전체를 압축 해제 → AI모드_설치관리자.exe → 게임 폴더 선택 → 설치 / 적용. 기능 설정을 바꾼 후 게임을 다시 시작하세요. 해제는 원본 복구를 사용합니다.

통합 인사와1군단 자동 내정은 새 설치에서 기본 꺼짐입니다. 기존 설정은 보존합니다. 한국어 Complete Edition 지원 빌드용입니다.
