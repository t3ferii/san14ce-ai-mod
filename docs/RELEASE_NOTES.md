# 삼국지14 CE AI·편의·최적화 모드 v12.22-rc1 (시험 배포)

v12.21 이후 로컬 설치에서 추가·수정한 기능을 공개용 **무로그 빌드**로 통합했습니다. 새 기능 전체의 실게임 확인이 남아 시험 배포로 제공합니다. 기존 정식 배포 v12.21은 유지합니다. **미서명**입니다.

## v12.22-rc1 변경점

- **예상 피해량**: 칼 등급 대신 현재 조건의 1회 병사 피해를 양쪽에 표시하고, 성·관문·시설은 내구 피해도 표시합니다. 표시만 바꾸며 전투 피해 규칙은 바꾸지 않습니다. 기본 ON.
- **건물파괴 지역 전체 피해**: 성공 시 원작이 계산한 피해량을 선택 지역의 적 군사시설·장애물·함정 각각에 적용합니다. 성·관문·아군·동맹·중립은 제외합니다. 피해량을 나누지 않고 원래 대상에 중복 적용하지 않습니다. 세력 번호를 군주 무장 번호로 오인하던 문제도 수정했습니다. 기본 OFF.
- **임무 일관성 v2**: 목표 성 8칸 안 공성 시설 1개, 건설 대기 없음, 원작 목표 성 공격 우선, 적 성·관문 공격 중 정지 퇴각 제외, 경로상 적 지역 작업 목록을 적용합니다. 원작 출진을 기본으로 하며 여유 병력 4만 이상 등의 조건에서 인접선으로 연결된 적 성을 검토합니다. 기본 ON. 함께 쓸 수 없는 정기 선제 출진·집단 진군·호위 지원은 설치기와 DLL 양쪽에서 막습니다.
- **AI 호전성 최대**: AI 설정 단계·진행 간격과 컴퓨터 무장의 호전·야망 조회를 보완합니다. 계략 성향은 바꾸지 않습니다. 기본 ON.
- **출진 후 재점검 수정**: v2에서 원작 노드 #10114/#10115가 아군 총전력을 한 거점 전력으로 덮어써 불필요한 회군을 판단할 수 있던 계산을 보완합니다.
- **설정·설치**: 5개 탭·57개 항목. 개발용 설정을 기능설정.ini로 모았습니다. 동일 해시 파일은 교체를 생략하고 파일 잠금 오류를 제한적으로 재시도합니다. v12.21의 해제 레이아웃 복구도 유지합니다.

## 설치·확인 범위

게임 종료 → SAN14_AI_v12.22-rc1_integrated.zip **전체 압축 해제** → AI모드_설치관리자.exe → 게임 폴더 선택 → 설치 / 적용. 기능을 바꾸면 게임을 재시작합니다. 기존 설정은 보존하며 새 설치에서는 건물파괴 전체 피해·통합 인사·1군단 자동 내정이 OFF입니다. 해제는 원본 복구를 사용합니다.

한국어 Complete Edition 지원 빌드용입니다. 원본 EXE·사용자 세이브·개발용 로그·백업은 포함하지 않습니다. 이번 GitHub 갱신 때문에 사용자의 게임 설치를 교체하지 않았습니다.

필수 dll-split -Build와 로컬 진단 빌드 통과. 일반 어댑터1595개·출진2032개·DLL 경계37개/실패 원복20개·로더63개·배포 노출8개·설치기 정적262개/설정 왕복76개, 건물파괴176개/원작 지문9범위, 예상 피해70개/원작 지문12범위가 통과했습니다. ZIP 격리 설치·업데이트·복구는 설치기 포함판133개, EXE 없는 판131개를 통과했습니다. 모의·파일 검사는 실게임 검증과 다릅니다. 예상 피해의 실제 감소량 대조, 건물파괴 전체 적용, 새 AI 판단·장기 안정성은 미확인입니다. v12.9의 실행 중 종료 보고 원인은 미확정이며 새 버전이 이를 해결했다고 주장하지 않습니다.
