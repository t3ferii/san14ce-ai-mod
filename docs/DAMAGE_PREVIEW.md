# 전투력대체 예상 피해량

편의성 탭에 `전투력대체 예상 피해량`을 추가했다. 기존 칼 5개와 10일 뒤 잔여 병사 표시를, 현재 조건에서 한 번 공격할 때의 예상 피해로 바꾼다. 전투 규칙과 실제 피해 적용은 변경하지 않는다.

2026-10-21 사용자 요청으로 로컬 버전 `v12.21-damage-preview-local1`을 설치하고 켰다. 기존 전투 DLL과 진단 로그 설정을 보존했다. 이후 사용자 제공 화면에서 조인↔한당·장의 및 강주 비교 표시를 확인했다. 실제 적용된 병력 피해 대조는 미확인이다. 공유 ZIP은 생성하지 않았다.

## 표시와 설정

- 부대 선택 후 적 부대에 마우스를 올리면 양쪽 이름 아래에 각자가 **주는 병사 피해**를 `123명` 형식으로 표시한다. 오른쪽 값은 상대가 우리 부대에 주는 피해다.
- 성·관문은 주는 병사 피해, 받는 병사 피해와 별도 `내구 N` 피해를 표시한다.
- 망루·투석대 등 일반 공격 시설은 병사 공격과 내구 피해를 구분한다. 병사가 없는 시설에 주는 병사 피해는 0이며, 공격 기능이 없는 시설의 반격도 0이다. 미완성 시설은 반격하지 않는다.
- 제목은 `예상 피해(1회)`다. 일수 환산이나 10일 누적 예측이 아니다. 대상이 바뀌면 즉시, 같은 대상의 수치는 최대 초당 5회 갱신한다.
- 키는 `[officer_ui] damage_preview=1`, 기본 ON이다. 편의성 묶음과 함께 켜져야 한다. OFF에서는 원래 전투력 표시를 사용한다.

`1회`는 해당 공격이 실제로 발생했을 때의 피해다. 사거리·공격 주기·명령 실행 여부를 보장하거나 미래의 교전을 시뮬레이션하지 않는다. 전법, 다수 부대의 동시 공격, 이후 사기·병력·내구 변화도 누적하지 않는다.

## 구현 근거와 소유권

소유 DLL은 `SAN14_Convenience.dll` 하나다. `src/native_damage_preview.inl`이 기존 대상 비교 UI의 RVA `7FA230`을 감싸며, 원래 UI 콜백 스레드에서만 읽기용 능력치·피해 계산 함수를 호출한다. 원본 함수 실행 후 기존 레이아웃의 문구·숫자를 바꾸고 칼 부분을 숨긴다. 외부 원격 호출, 게임 데이터 쓰기, 피해 적용 함수 호출은 없다.

| 용도 | 현재 빌드 RVA와 처리 |
|---|---|
| 원래 대상 비교 UI | `7FA230`, 패널 `+130`, 칼 파트 17~26, 숫자 31~32 |
| 병사 피해 | 원작 `16A1D0`, 공군 `2B21A0`, 공성 `2B2440`, 방어 `2A9E50` |
| 파성 | 읽기용 `2AA2E0`의 결과에 내구 상한·완파 거리·관련 세력 효과를 계산 |
| 일반 시설 공격 | 시설 종류·완성 여부·내구 비율·효과 계수와 정책/개성 보정 후 원작 병사 피해 함수 사용 |
| 문구·가시성 | 원작 `930D20`, `92F810`, 기존 패널 표시 슬롯 `+C8` |

`29E840`(내구 적용), `191760`(시설 공격 실행)은 분석 근거로만 사용하며 호출하지 않는다. 내구 피해와 시설 공격의 일부 계산은 읽기 전용으로 재현했다. 특수 시나리오의 별도 보정과 모든 성벽 예외까지 일치한다는 검증은 하지 않았다.

지원 EXE SHA256은 `87ed4e46590e0939c9efcaef14fa0f892917604dfda86e0a4be319fccffa2d6a`다. 검사 전용 해제 PE와 원작 호출부·분기·ABI를 대조하고 12개 코드 범위 지문을 생성했다. 불일치하면 새 UI 훅을 설치하지 않는다. 원래 함수의 null 입력 분기도 보존한다.

상세 조사: 전투 계산, 대상 비교 UI. 지문 재생성 도구는 `tools/verify_damage_preview_native.py --generate`다.

## 검사와 남은 확인

- 피해 표시 fixture 70개 통과: 양방향 피해, 대상 변경·재사용, 시설/성, 미완성 시설, 아군/빈 대상 숨김, 설정 OFF, 갱신 제한, 게임 데이터 비변경 등.
- 현재 EXE/검사용 PE 대조: 12개 코드 범위와 4개 호출부 통과.
- `tools/check_feature.ps1 -Feature damage-preview -Build`와 필수 `-Feature dll-split -Build` 통과. 세 DLL 분리 빌드·로더/내보내기 검사 포함.
- 설치기 격리 fixture 62개 통과. 편의성 항목의 기본 체크·탭·문구 및 렌더 이미지를 확인했다. 게임 화면 검사가 아니다.
- 사용자 제공 화면에서 부대·강주 대상 한글/숫자 표시를 확인했다. 부대 피해 4방향은 화면 공방의 절삭 오차 범위와 양립한다. 수치 대조와 성의 13명 설명. 실제 병력/내구 감소, 관문·시설 화면, 장기 안정성은 미확인이다.

개발 검사 기록은 `build/development/damage_preview/verification.json`, 개별 로그와 `native_evidence.json`에 있다. 일반 개발 DLL은 `build/development/loader_split/SAN14_Convenience.dll`이다.

설치에는 기존 진단 상태를 유지하기 위해 `build/development/loader_split_diagnostic/SAN14_Convenience.dll`을 다시 빌드해 사용했다. `tools/install_damage_preview.py`가 실제 설치된 두 진단 DLL을 기존 진단 빌드와 대조하고, 오래된 소유권 해시를 백업 후 정합화한 뒤 원래 guarded Apply를 실행했다. 전투 DLL과 로더는 현재 설치본을 그대로 패키지에 넣었다. 편의 DLL·45항목 설치기·기능 선택 목록을 갱신했으며 기존 모든 설정값을 보존하고 `officer_ui.damage_preview=1`을 추가했다.

설치 근거는 `build/damage_preview_installation.json`, 적용 패키지는 `build/input_package`와 `build/damage_preview_local_package`다. 세 DLL의 설치/Apply 해시 일치, 원본 EXE·화면 레이아웃·진단 설정 보존, 기존 전투 DLL 비변경을 확인했다. 업데이트 전 실제 DLL·GUI·설정·소유권 기록·Apply 자료는 `backup/damage_preview_install_208e61a705cd49b68f879842a85d5abb`에 있고, guarded Apply 자체 백업도 별도로 남았다. 공개 배포에는 당시 최신 소스/설치 기준으로 별도 검증이 필요하다.
