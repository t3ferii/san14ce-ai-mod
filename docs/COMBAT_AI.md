# 전투 AI의 현재 규칙

`SAN14_CombatAI.dll`이 기존 AI 호출 안에서 판단한다. `native_campaign*.inl`, `native_sortie*.inl`, `native_facilities.inl`, `native_obstacles.inl`과 정책 헤더가 구현이다. 독립 `combat_v2`는 미연결이며 이전 목표 퇴각 정책도 설치하지 않는다.

v12.22의 새 설치는 임무 일관성 v2와 AI 호전성 최대가 기본 ON이다. v2에서는 목표 성 8칸 안 공성 시설 1개만 건설하고 건설 대기로 세우지 않으며, 원작이 목표 성을 공격하면 모드 진행이 비켜선다. 적 성·관문 공격 중 정지 퇴각을 제외하고, 경로의 적 지역을 원작 작업 목록에 넣는다. 정기 선제 출진·30일 집단 진군·호위 지원은 v2와 함께 사용할 수 없다. 아래 표는 해당 스위치가 활성화된 경우의 경로다.

원작 출진 후 재점검 노드 #10114/#10115가 아군 총전력을 한 거점 전력으로 덮어쓰던 계산을 v2 안에서 보완한다. 거점 전력의 적측 차감은 유지하고 아군 합계를 복원한다. AI 호전성 옵션은 AI 단계와 진행 간격, 컴퓨터 무장의 호전·야망 조회를 보완하며 계략 항목34는 그대로 둔다. 실제 출진·회군 결과와 장기 안정성은 미확인이다.

게임성 탭의 **지원·내정 군단 출진 제한**은 편의 묶음에 속한다. 플레이어 위임 군단에서 지원은 수송 출진만, 내정은 군사 출진을 막고 수송·건설은 허용한다. 전투 DLL이 있으면 기존 `sortie_dispatch`가, 없으면 편의 DLL의 별도 진입 훅이 `1EC890`에서 검사한다. `native_district_intercept*.inl`이 공통 정책이며 두 DLL이 같은 입구를 동시에 소유하지 않는다. 해당 군단 거점의 반경15칸 적 근접 수송 제외 조건도 보완한다. [함수 근거](GITHUB_기능상세.md).

| 기능 | 현재 규칙·스위치 |
|---|---|
| 출진·편성 | sortie_formation: 원작 자원·무장·진형·경로 조건을 통과하는 군세 편성, 역할별 부대와 1,000명 지원, 공성 진형 8,000명 상한 |
| 선제 출진 | departures: 10일 주기 추가 출진 검토 |
| 현장 행동 | 주변 지역 점령·건설·합류와 원작 경로를 이용. 건설 완료 횟수 제한이나 성 앞이라는 이유만으로 공격을 앞세우는 규칙은 없음 |
| 집단 진군 | group_advance: 집결 군세가 실제 30일 정지하면 대열·최종 목표를 유지해 진군. 끄면 새로운 집단 진군 시작을 막음 |
| 정지 퇴각 | stationary_retreat: 일반 부대가 같은 타일에서 40일 정지하면 퇴각. 사기회복·건설·교전·피해만으로 기간을 연장하지 않음 |
| 사기·지원 | morale: 사기 회복 우선. support: 호위·동행 지원 요청 |
| 병참 | combat_cut: 모드 군세의 플레이어 병참선 차단 검토 |
| 피격·공성 고정 | hit_response: 실제 적 성/관문 피격에 따른 목표 고정과 피격 상태 기록. 모드가 주변 적을 새로 추격/요격하는 이전 규칙은 제거됨 |
| 장애물 | obstacle: 자격 있는 중립 방벽 파괴. 피격을 근거로 한 경로 사유는 hit_response도 필요 |
| 조기 회군 | recall_veto: 갓 출진한 공격 군단의 즉시 회군 억제 |
| 방벽 | ai_wall_block: 컴퓨터 세력 방벽 건설 차단 |

명령 잠금은 **실제 적 성/관문 피해 목표**와 **30일 정지 후 집단 진군** 두 경로다. 후자는 자신의 이동 작성자만 잠금을 통과하며 대열·구성을 유지한다. 일반 공성 명령은 교체할 수 있다. 건설 3회 제한·20일 진군·20일 정지 퇴각·추행진 일괄 제외는 과거 정책이다.

직접 플레이어 명령과 원작 요격·원군 판단을 보존한다. 숫자만 바꾸기 전에 모든 경쟁 명령 작성자와 호출 순서를 확인한다. action/target-kind, 목표 점령, 같은 날 재호출, 부대 식별 재사용, 퇴각·이동 범위 해제를 함께 검증한다.

검사: `check_feature.ps1 -Feature ai -List`, `campaign-revision`, `sortie`, 경계 변경은 `dll-split`. 과거 v11.10/v11.11 경로 충돌판은 재설치 금지다. v12.9 종료 보고는 별도 미해결이며 전투 AI 원인으로 확정되지 않았다. 함수 주소·ABI는 NATIVE_FUNCTIONS, 당시 수정 경위는 역사 보관 ZIP를 참고한다.
