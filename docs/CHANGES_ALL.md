## 문서 정리 (2026-10-19)

구버전 현재 안내를 주제별 문서로 교체했다. 이전 START·변경표·중복 배포 문서·버전별 개발 기록은 역사 보관 ZIP에 보존했다. 현재 소스/설치/후보를 구별하고, dist 구버전과 게임 DLL·EXE·설정은 유지한다. 실제 수정 내역·보존 검사는 `build/development/docs_cleanup`에 기록한다.

정리 전 상세 이력은 역사 ZIP의 docs/history/20261019/CHANGES_ALL_before_cleanup.md. 과거 문서에 있는 설치 명령·"현재 적용" 문구는 당시 상황이다.
