# 월드맵 지역담당관 표시

`SAN14_Convenience.dll`이 플레이어 점령 지역의 담당관을 표시한다. 지역명 왼쪽·세로 중앙에 원작 초상화를 75%로 표시하고 공석은 빈 초상화·중립 회색 테두리로 나타낸다. 임명·변경은 기존 지역내정에서만 한다.

원작 이름표의 자식이므로 이동·숨김을 상속하며 최대 확대부터 네 번 축소한 줌 0~4에서만 표시한다. 관련개성은 원작 지역명 part22의 실제 끝에서 4 UI픽셀 뒤에 붙는다. 이름 geometry가 준비되지 않으면 개성도 숨긴다.

v12.16: 성 이름표(`CFootholdInfoLayout`, vtable 13999B8)에도 성 지역의 개발 담당관을 표시한다. 이름표 +1F0 객체 +4E 거점 번호 → 건물 +10 중심 칸 → 타일 +12 지역(원작 22D500·22A7B0과 같은 계산). 성 이름표의 관련개성은 초상화 아래에 둔다. 관련개성 글씨는 18pt 흰색 + 검은 1픽셀 외곽선(검은 복사본 4개)이다.

스위치: `[domestic] region_officers`(기본 1), `region_officer_traits`(기본 1, 앞 기능에 종속). 편의 묶음이 켜져야 하며 변경 후 게임을 재시작한다.

## 캐시·작업 분산

개성 정의·무장 슬롯·문자열·초상화 자원을 캐시하며 상태/위치가 바뀔 때만 해당 원작 작업을 실행한다. 얼굴 생성·이미지 적재·개성 글자 생성을 이름표 한 바퀴당 하나로 나누고 100ms 복구 경로를 둔다. 새 지역 표시는 여러 번의 그리기에 걸쳐 완성될 수 있다.

v12.6 이후 지역담당관 전용 계측 타이머·콜백 카운터·상태 JSON·프로필 INI 읽기는 제거됐다. 일반 배포가 지역담당관 측정 파일을 새로 만들지는 않는다. 이전 로그는 연구 근거로 보존한다.

## 검증 범위

- v12.5 간격은 사용자 정상 확인이다. 이후 작업 분산 효과·클릭 통과·실제 FPS/지연 감소는 미측정이다.
- 고정 상태 모의 1만 회에서 추가 원작 직접 호출·텍스트 재설정·자원 재생성 0을 검사했다. 모의 호출 0은 실제 FPS 보장이 아니다.
- 마지막 실측은 v12.4 진단판의 30.032초다. 계측 구간 합계 173.236ms, 439,808 콜백 평균 0.394µs, 최대 24.902ms, 추가 원작 직접 호출 105회였다. 최대 지연의 원인을 분리 계측하지 않았으며 현재 빌드의 CPU/FPS 수치로 일반화하지 않는다.
- v12.10 설치 기록은 어댑터 152개·현재 EXE 43범위/3슬롯을 포함한다. 최신 설치/후보의 실제 기록은 CURRENT에서 구분한다.
