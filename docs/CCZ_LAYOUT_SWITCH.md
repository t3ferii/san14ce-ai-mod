# 조조전 OFF·모드 해제 시 부대 UI 복원

2026-11-03 로컬 수정. 공개 v15.3과 구분하며 설치 버전·검사 결과는 [CURRENT](../development/CURRENT.md)를 따른다.

## 원인과 수정

헥스 지면에 붙인 부대 UI는 조조전 DLL만의 처리가 아니었다. 설치기가 `ScreenLayout.rdb` 색인 14개를 설정과 관계없이 적용했다. 따라서 `ccz_sprites=0`이어도 부대 초상화·병력·깃발/사기 배치가 남았다.

관련 KTID는 `3DA1641D`, `757F1A41`, `5C046EA3`이다. 세 번째의 배포 자료 `original_entry`가 원본이 아니라 과거 모드 bank28을 가리켜 해제 후에도 군단 초상화가 남았다. 첨부 분석을 그대로 적용하지 않고, 로컬 이전 백업의 실제 3개 레코드와 대조해 원래 참조를 확인했다.

| 항목 | 복원 참조 |
|---|---|
| 부대 깃발·사기 | `8a34e@15ee` |
| 부대 초상화·병력 | `8bf87@1030` |
| 군단 초상화 | `8d5cc@7d5` |

- `[groups] convenience=1` 및 `[ccz] ccz_sprites=1`일 때만 이 3개를 적용한다. OFF면 원본으로 복원하며 나머지 11개 화면 패치는 유지한다.
- 모드를 해제하면 14개 모두 복원한다. 현재 기록에 없는 과거 CCZ 참조는 정확한 locator와 실제 bank의 해당 payload가 우리 자료와 일치할 때만 복원한다. 외부 자료가 달라지면 보존한다.
- 기능 선택을 완료한 **후** 화면 패치 계획을 만든다. 선택 전의 값으로 계획을 만드는 순서로 되돌리지 않는다.
- ‘설정만 저장’도 설치된 DLL과 패키지가 같은 경우, 게임 종료 상태에서 기존 guarded Apply를 재사용해 배치를 동기화한다. 게임 실행 중이거나 패키지가 다르면 설정만 저장하고 종료 후 ‘설치 / 적용’이 필요하다고 알린다. 실행 중 UI나 메모리에 원격 쓰기를 하지 않는다.
- INI를 직접 편집한 경우에는 게임을 종료하고 설치관리자의 ‘설치 / 적용’을 실행한다. 재시작만으로 디스크 리소스 색인이 다시 작성되는 것은 아니다.

## INI·설치기 정리

GUI와 PowerShell 기능 카탈로그는 87개로 일치한다. 그중 사용 중지 4개는 기존 결정대로 숨기며 활성화하지 않는다.

- `[game_flow] fast_menu`: 예전 섹션 별칭. 현재 `[performance] fast_menu`로 이전한다. 현재 키가 있으면 현재 값을 우선한다.
- `[performance] strategy_batch`: 화면 손상으로 이미 폐기된 기능이다. UI에 되살리지 않고 오래된 INI 키를 정리한다.
- `[ccz_appearance] profile`: 누락된 체크박스가 아니라 인게임 조형 편집기의 문자열 데이터다. `Catalog.RawSettings`로 관리하며 그대로 보존한다.
- 그 밖의 알 수 없는 사용자 키는 삭제하지 않는다. GUI/PS가 일반 0/1 및 지형 진단0~3을 해석하는 기존 방식도 유지한다.
- `tools/audit_feature_settings.py`로 현재 INI의 카탈로그 항목·문자열 데이터·구형 키·미등록 키·중복 섹션/키를 읽기 전용 검사할 수 있다.

## 로컬 확인 방법

1. 게임을 종료하고 설치관리자 조조전 탭에서 ‘조조전 병종 그림’을 OFF로 저장/적용한다.
2. 게임을 시작해 부대 초상화·병력·사기·깃발과 군단 초상화가 원작 배치로 돌아왔는지 확인한다.
3. 게임 종료 후 ON으로 저장/적용하고 재시작해 기존 조조전 배치를 확인한다. 다른 편의 기능은 그대로 켜 둬도 된다.
4. 모드 전체 해제는 게임 종료 후 ‘모드 해제 (원본 복구)’를 사용한다. DLL 파일만 삭제하거나 RDB 스냅샷을 직접 덮어쓰지 않는다.

## 재현·검사 경로

- `tests/verify_ccz_layout_switch.ps1`: OFF 신규 설치, ON↔OFF, 상위 묶음 OFF, ON 이후 해제, bank28 잔존 참조, 외부 payload 보존. 복사본만 사용한다.
- `tests/verify_ccz_select.py`: 설치 후 설정만 저장으로 ON↔OFF를 바꾸고 DLL 불변·최종 해제를 확인한다. 로컬 후보 ZIP의 관리자 스크립트를 임시 게임 폴더에서 실행한다.
- `tests/verify_feature_migration.ps1`: GUI/PS 이전 결과, 현재 값 우선, 조형 문자열·사용자 데이터 보존.
- 기존 설치기 빌드·설정 왕복 검사, `tests/verify_layout_restore.ps1`, 배포 설치·복구 검사도 관련 근거다. 이 검사들은 실제 게임의 렌더링·클릭 확인을 대신하지 않는다.

근거: `data/diagnostics/ccz_ui_analysis_20261103/`, `build/development/ccz_layout_fix/traits9_layout.json`의 백업 지문. 원본 백업과 공개 배포 ZIP은 수정하지 않는다. DLL 코드와 local14 줌 복구·조형 설정창은 이번 수정 대상이 아니다.
