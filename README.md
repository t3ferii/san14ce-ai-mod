# 삼14CE AI교정 모드

## 모더용 소스 공개

[소스 수정·빌드 안내](docs/SOURCE_BUILD.md) · [AI 수정 지침](docs/AI_EDITING.md) · [검증 결과](docs/SOURCE_VALIDATION.md) · [수정·재배포 허용 범위](LICENSE)

`src/`, `tests/`, `tools/`, `installer/`, `distribution/`에서 원하는 기능을 fork하여 수정할 수 있습니다. 핵심 코드의 `AI-CONTRACT` 주석은 AI가 지켜야 할 스레드·ABI·훅 소유권·저장 호환성 제약을 설명합니다. **2026-10-26 개발 소스 스냅샷이며 정식 v13.3 DLL의 정확한 재현 소스로 보장하지 않습니다.** 전체 빌드에 필요한 원작 자료·외부 모드 payload는 [별도 의존성](docs/SOURCE_DEPENDENCIES.md)을 확인하세요.


길어지는 「전략중」 대기, 손이 많이 가는 등용과 내정, 아쉬웠던 컴퓨터의 전쟁 운영을 함께 손봤습니다. **기다리는 시간은 줄이고, 천하를 다투는 재미에 더 집중해 보세요.**

- **맞서 싸울 만한 컴퓨터** — 출진 편성부터 공성·병참·회군 판단까지 보완합니다.
- **반복 관리는 한결 가볍게** — 자동 등용, 균형 내정, 명품 정리로 손이 많이 가는 일을 덜어줍니다.
- **판단에 필요한 정보를 한눈에** — 예상 피해량, 숨겨진 충성도, 담당관 개성과 귀환 예정일을 보여줍니다.
- **내 취향대로 골라 쓰기** — 설치기의 전투·편의성·성능·게임성 탭에서 원하는 기능만 선택하세요.

> **v13.3 긴급 수정 (2026-10-26)** — 경로 탐색 가속의 메모리 누수를 수정했습니다. v13.1·v13.2 사용자는 업데이트해 주세요. 기존에 골라 둔 기능과 설정은 그대로 이어집니다.

## 처음 설치한다면

1. 게임을 종료하고 [최신 릴리스](https://github.com/t3ferii/san14ce-ai-mod/releases/latest)의 ZIP을 **전체 압축 해제**합니다.
2. `AI모드_설치관리자.exe`를 실행합니다. **게임 폴더 변경**에서 `SAN14CE_KO.exe`가 있는 폴더를 고릅니다.
3. 원하는 기능을 고르고 **설치 / 적용**을 누른 뒤, 평소처럼 Steam이나 런처로 게임을 시작하세요.
4. 나중에 기능을 바꾸고 싶으면 **설정만 저장**하고 게임을 다시 시작하면 됩니다. 업데이트해도 기존 선택은 보존됩니다.
5. 원래 게임으로 돌아가려면 **모드 해제 (원본 복구)**를 누르세요. 동봉된 적용·복구 CMD도 사용할 수 있습니다.

**한국어 Complete Edition(CE) 64비트용**입니다. 지원하는 실행 파일인지는 설치 관리자가 확인합니다. 일반 플레이에서는 **기타(개발용)** 탭을 꺼두세요.

공개 v13.3 설치기에는 **74개 항목**이 있습니다. 대부분 기본으로 켜져 있고, **건물파괴 지역 전체 피해·통합 인사·1군단 자동 내정**은 원하는 분이 직접 켜서 사용합니다.

## 건물파괴 한 수로 지역 시설을 흔들기

**건물파괴 지역 전체 피해**를 켜면 계략 성공 시 선택한 지역의 적 군사시설·장애물·함정에 각각 피해를 줍니다. 시설이 밀집한 지역을 공략할 때 새로운 선택지가 됩니다. 플레이어와 컴퓨터 모두 적용하며 **기본은 OFF**입니다. [자세한 효과](docs/BUILDING_DESTRUCTION.md)

## 개발 중: 모아 둔 군정으로 끝까지 대응하기

**아래 두 기능은 로컬 후보판에 추가되었으며, 공개 v13.3 ZIP에는 아직 들어 있지 않습니다.**

「군정은 충분한데 왜 100%까지만 넣어야 할까?」라는 아쉬움을 줄이기 위해 만들고 있습니다.

- **군정 100% 초과 투입** — 컴퓨터가 시작한 친선·동맹·포로반환·공격요청 교섭에서 보유 군정까지 투입합니다. 초과 방어분도 남아 상대의 추가 투입에 대응합니다.
- **마지막 추가 대응** — 컴퓨터의 마지막 응답을 본 뒤 플레이어가 한 번 더 군정을 투입합니다. 그 뒤 최종 판정으로 넘어갑니다.

두 기능은 따로 켜고 끌 수 있습니다. 자동 검사와 로컬 설치를 마쳤으며 실제 게임에서 입력·표시·결과 확인을 진행할 예정입니다.
