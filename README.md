## 설치와 사용

1. 게임을 종료하고 릴리스의 `SAN14_AI_v13.3_integrated.zip`을 **전체 압축 해제**합니다.
2. `AI모드_설치관리자.exe`를 실행합니다. 게임 폴더가 다르면 **게임 폴더 변경**에서 `SAN14CE_KO.exe`가 있는 폴더를 고릅니다.
3. 다섯 탭에서 기능을 선택하고 **설치 / 적용**을 누릅니다. 이후 평소처럼 Steam/런처로 실행합니다.
4. 기능을 바꾸면 **설정만 저장** 후 게임을 다시 시작합니다. 기존 설정은 업데이트할 때 보존합니다.
5. 해제할 때는 **모드 해제 (원본 복구)**를 사용합니다. 설치 관리자를 못 쓰면 동봉한 적용·복구 CMD를 실행합니다.
6. 기타(개발용) 탭은 꺼주세요. 게임 실행시 렉이 걸릴 수 있고 개발용 진단로그입니다.

대상은 한국어 CE 64비트의 지원 빌드입니다. PK 단독판·다른 언어·다른 실행 파일 전체에 대한 호환을 보장하지 않습니다. 설치기는 빌드를 확인하고, 게임 실행 시에도 연결할 원작 코드를 검사합니다. 원본 게임 EXE는 배포하지 않습니다. 

설치기에는 **묶음 4개와 세부 기능 70개, 총 74개 항목**이 있습니다. 새 설치의 기본값은 대부분 켜짐이며 **통합 인사**와 **1군단 자동 내정**은 꺼짐입니다. 기존 사용자의 선택과 새 설치 기본값은 다릅니다.

## v12.22 계열에서 추가·수정한 기능

- **예상 피해량**(편의성, 기본 ON): 칼 등급 대신 양쪽의 1회 병사 피해와 시설 내구 피해를 표시합니다. [표시 범위](docs/DAMAGE_PREVIEW.md).
- **건물파괴 지역 전체 피해**(게임성, 기본 OFF): 성공 시 선택 지역의 적 군사시설·장애물·함정 각각에 원래 피해량을 적용합니다. 성·관문·아군·동맹·중립은 제외합니다. [대상과 예외](docs/BUILDING_DESTRUCTION.md).
- **임무 일관성 v2**(전투, 기본 ON): 목표 성 8칸 안 공성 시설 1개, 건설 대기 없음, 원작 목표 성 공격 우선, 적 성·관문 공격 중 정지 퇴각 제외를 적용합니다. 경로의 적 지역을 원작 작업 목록에 추가하고 여유 병력 4만 이상 등의 조건에서 인접선으로 연결된 적 성을 검토합니다. 켜면 정기 선제 출진·30일 집단 진군·호위 지원은 자동으로 비활성화됩니다.
- **AI 호전성 최대**(전투, 기본 ON): 원작 AI 설정 단계·진행 간격과 컴퓨터 무장의 호전·야망 조회를 보완합니다. 계략 성향은 덮어쓰지 않습니다.
- **출진 후 재점검**: 임무 일관성 v2에서 원작의 아군 전력 합계가 한 거점 전력으로 덮이는 것을 막아 출진 직후 불필요한 회군 판단을 보완합니다.
- **기타(개발용)** 탭: 설정을 `기능설정.ini`로 통합했습니다. 공개 DLL은 로그 코드를 제외하므로 진단 로그·추적을 켜도 기록되지 않습니다.

아래 전투 표의 정기 선제 출진·집단 진군·호위 지원은 임무 일관성 v2를 끈 경우의 경로입니다. 새 설치에서는 v2가 켜집니다. 건물파괴 전체 피해·통합 인사·1군단 자동 내정은 기본 OFF입니다. 기존 설정은 보존합니다.

## 전쟁에서 달라지는 점

전투 탭은 컴퓨터가 운용하는 부대의 판단을 교정합니다. 부대가 실제로 움직일 수 있는지, 병력·무장·금·군량이 있는지는 원작 명령과 경로 검사를 거칩니다. 아래 세부 기능을 꺼도 다른 전투 기능의 공통 판단이 남을 수 있으며, 전투 변경 전체를 끄려면 **전투 AI 교정 전체**를 끕니다.

| 기능 | 게임에서 바뀌는 행동 |
|---|---|
| 군세 출진 편성 | 병력과 사용 가능한 무장·진형에 맞춰 2~7부대를 편성합니다. 앞줄·후열·지원 역할을 나누며 1,000명 지원 부대를 사용할 수 있습니다. 공성 진형은 최대 8,000명으로 배분하고, 목적에 맞는 야전 진형으로 바꾸는 경로도 있습니다. |

## 전투 설정과 진행 속도

**숙련 모드 공방 설정 + 인접지역 효과**를 켜면 자세력·타세력의 기본 공방과 인접지역 효과를 조절할 수 있습니다. 원작의 무장·진형·병력·사기 계산 결과에 적용되는 배율을 조절합니다.

예를 들어 기본 공방 100, 인접효과 4라면 완전 점령 인접 지역 하나당 4%를 더합니다. 기본 공방 50, 인접효과 200이면 기본 배율 0.5에 지역 하나당 2.0을 더합니다. 부분 점령과 세력 특성 보정은 별도 원작 계산을 유지합니다. 컴퓨터끼리의 실제 전투는 기존 기본 배율과 인접 4%를 유지합니다. **이 설정으로 저장한 게임은 기능을 켠 채로 이어 하는 것을 전제로 합니다.**

진행 메뉴에는 `>>>>` **×4**, `>>>>>` **×8** 버튼을 추가합니다. 기존 `>>>` 대비이며 **게임 옵션 60fps 기준**입니다. 30fps에서는 최대 ×4이고 실제 하루 처리량에 따라 체감 속도는 낮아집니다. ×8은 모든 하루 처리가 끝난 프레임에 한 번 더 시작하는 방식입니다. 버튼 주변 여유 영역과 짧은 유지 시간을 두어 마우스를 옮길 때 팝업이 바로 닫히는 것을 줄입니다.

|---|---|
| 거리·AI 진입 계산 | 반복 거리 계산을 빠르게 수행합니다. 전투 능력치나 이동 가능 지형을 새로 정하는 기능은 아닙니다. |
| 이름 탐색 | 원작과 같은 이름 조회 결과를 더 빠르게 찾도록 교체합니다. |
| 화면 레이아웃 보관 | 느리게 읽은 화면 자료를 메모리에 유지해 같은 자료를 다시 읽는 대기를 줄입니다. 최대 512개를 보관하므로 메모리 사용과 바꾸는 기능입니다. |
| 빠른 자동저장 압축 | 원작 형식으로 압축한 뒤 즉시 풀어 비교하고, 맞지 않으면 원작 압축기로 돌아갑니다. 기존 측정에서는 약 1.7초 작업이 약 0.1초였고 파일은 약 9% 커졌습니다. 모든 PC·저장에 같은 수치를 보장하지 않습니다. |

일반 배포는 함수 시간 측정을 포함하지 않으며 AI 추적·GPU/레이아웃 진단은 기본 꺼짐입니다. 빠른 진행과 계산 최적화는 별개 기능입니다.

## 시험 기능: 통합 인사

**기본 꺼짐**입니다. 지도에서 통합 인사 버튼을 열어 플레이어 세력 무장을 이름·소속·능력·진형·전법·정책·개성·공적·관계·연계 등으로 검색합니다. 다른 조건끼리는 모두 충족, 같은 조건의 여러 값은 하나만 충족하면 됩니다. 검색 조건과 선택 무장을 따로 관리합니다.

집단편제, 의형제, 관직·명품 수여, 이동, 여러 무장의 전법 습득, 교역을 일괄 처리하는 경로가 있습니다. 성공한 무장×행동마다 중앙군단 명령서 1개를 사용하며 금·전법서·공물은 기존 명령이 소비합니다. 실행 전 확인창과 완료·제외·부족·실패 집계를 표시합니다.

무력형·지력형별 전법 우선순위를 정해 플레이어 출진창에서 호환되는 전법 3개를 자동 선택할 수 있습니다. 자동 선택 자체도 기본 꺼짐이며 이후 수동 선택은 유지합니다. 이 기능은 실제 게임의 최종 화면 배치·입력·일괄 결과·저장 재로드 확인이 남아 있습니다. [구현 범위와 제한](docs/UNIFIED_PERSONNEL.md).

## 확인된 범위

위 설명은 현재 소스의 설정 처리·연결 함수·정책을 대조한 내용입니다. 파일 검사와 자동 검사는 실제 게임 화면·장기 플레이 검증과 구분합니다. v12.9 실행 중 종료 보고는 원인이 확정되지 않았고, 현재 ×8 진행과 자동점령 연출의 장기 안정성을 완전히 확인한 상태도 아닙니다.

v12.21은 DLL을 변경하지 않습니다. 새 검사는 설치 기록이 없거나 오래된 경우의 화면 레이아웃 원본 복구, 해제 후 잔여 정리, 다른 레이아웃 모드 항목 보존(실제 색인 사본 21개)과 배포 ZIP 설치·복구(133개)입니다. 일반 로그를 꺼도 논공·명품창고 저장은 필요한 별도 동작으로 남습니다.
